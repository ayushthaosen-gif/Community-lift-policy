# Community Lift Policy Lab

An interactive, transparent queue simulation comparing pet priority, a preferred pet lift, and first arrival with voluntary sharing.

The model shows average wait, 95th-percentile wait, and the waiting-time gap between residents and pet parties. All assumptions are visible and adjustable.

## Run locally

```bash
npm install
npm run dev
```

## Publish with GitHub Pages

Create a GitHub repository, push this folder to its `main` branch, then enable **Settings → Pages → Source → GitHub Actions**. The included workflow publishes the static site automatically.

## Limitation

This is an illustrative decision aid, not a safety, engineering, or legal finding. It does not model weight capacity, floor-specific demand, emergencies, or breakdowns during a run.
